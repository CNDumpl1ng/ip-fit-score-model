# Game IP Collaboration Fit Scoring Model

A public, reusable notebook for evaluating whether a game should collaborate with a candidate IP.

This repository contains a generic scoring framework using fictional sample data and placeholder IPs. It is designed for public sharing and can be adapted to real community, social, or player-discussion data.

## Main Features

- Core user overlap scoring
- Channel activity overlap
- High-engagement user overlap
- Purchase intent detection
- Collaboration expectation detection
- Sentiment and fit-risk detection
- UGC and creator-discussion signals
- Automated score and optional human-weighted score
- Excel report export
